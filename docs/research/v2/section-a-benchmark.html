Executive summary

The through-line of the whole Section-A corpus: the harness is deep on build + verify and thin on operate + govern. Its packaging format (native SKILL.md), its scaffold generators, its role-agent decomposition, its /ship+/qa gate stack, and its three-tier memory model are all already best-in-class — they land on KEEP or KEEP+HARDEN across the board. The dependency tree is clean (npm audit = 0 vulns, 100% permissive licenses). What the enterprise pivot exposes is not a wrong foundation but a set of missing operate/govern surfaces: no operational runbook artifact, no MCP trust policy, no install-time behavioural supply-chain scanning, no AI-output guardrail, no OpenAPI contract, no compliance-evidence pipeline.

What we are notably ahead on (don't lose)

A deliberately cheap read-only recon tier (scout on haiku) — most OSS harnesses have no cost-tiered recon; a shipped ops agent (sre) and security-design agent (security-architect on opus) — most harnesses stop at a single code reviewer; deterministic policy-as-hooks + ESLint rather than a nondeterministic guardrail agent for code-shape rules; a three-tier memory model (durable ADR → cross-session agent-memory.md → in-flight SESSION-HANDOFF.md) that survives forks; and a clean, fully-permissive dependency tree with zero AGPL/GPL/SSPL/BUSL/Elastic anywhere in the shipped set.
The one-line thesisFormat, generators, agents, gates, and memory are already best-in-class (KEEP+HARDEN). The real work is breadth on operate + govern — led by /runbook, the MCP trust policy, the install-time supply-chain triad, and the AI-output ai-eval gate — all applied through the harness's own proven pattern: a gate plus a committed adjudication artifact.

A1

Skills & golden-path workflows

Meta about the harness itself, not npm libraries. Candidates are skill/workflow-packaging approaches + golden-path generators in the ecosystem, and the categories of skills a best-in-class enterprise Claude harness should ship. What we ship today: 28 skills + 4 agents, each a SKILL.md (YAML frontmatter + Markdown body), several backed by a scripts/*.mjs generator — exactly the Anthropic Agent Skills format. The 2026 landscape: Anthropic unified slash-commands and skills into one Agent Skills primitive (Oct 2025), shipped the anthropics/skills reference (160k★) and the plugin marketplace; the community exploded (Superpowers 252k★). We are on the right side of this convergence; the gaps are in breadth of lifecycle coverage, not format.
