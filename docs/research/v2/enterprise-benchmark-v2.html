Executive summary

The stack is largely right — the hard architectural bets (Next 16 + React 19 RSC, the Prisma-7 WASM rewrite, the AntD→Tailwind/shadcn migration, zod-everywhere, Playwright) all survive scrutiny and land on KEEP. What the enterprise pivot exposes is not a wrong foundation but three under-built frontiers: an entire missing AI/agent layer (C07), the self-host operational rail the Vercel-era stack never needed (Docker image, proxy, secrets, backups, observability backbone — C09/C10/C11), and a handful of individually cheap but load-bearing corrections (Node 22→24, bcryptjs→Argon2id, the in-memory rate-limiter bug, a pinned-and-compromised Trivy).

The pivot that reframes every verdict

Enterprise-only (the personal/prototype tier is dropped) · deploy-per-tenant (one container + one DB + one IdP per tenant — no in-app row-level multi-tenancy) · Docker-first self-hosted dockerized Postgres by default (Neon optional) · compose now, k8s-ready later (no k8s in v1) · Claude-first for AI. Deploy-per-tenant is the single most consequential decision: it collapses the value of multi-tenant SSO brokers, per-tenant metering products, and horizontally-scaling observability backends — each tenant is a bounded context, so "per-tenant" becomes "per-deployment" throughout.

The load-bearing calls

  1. Node 22 → Node 24 (P0). Node 22 is Maintenance-LTS (security-only after Oct 2026, EOL Apr 2027). A drop-in bump removes a 2027 cliff.
  2. The in-memory rate-limiter is a correctness bug (P0), not a nice-to-have — under >1 replica the real limit becomes N×configured. Fix = Valkey + rate-limiter-flexible, in-memory fallback for single-container tenants.
  3. Pin the compromised Trivy (P0). The scanner that runs inside /ship shipped a credential stealer on 2026-03-19. Pin trivy ≤0.69.3 / trivy-action v0.35.0 / setup-trivy v0.2.6 and SHA-pin every Action.
  4. Build the AI layer, don't buy a framework (P0). A ~100-line wrapper on Anthropic's native Tool Runner; Managed Agents for hosted/scheduled; defer Mastra/LangGraph. Add an ai-eval gate so model outputs are gated the way code is.
  5. bcryptjs → @node-rs/argon2 (P0). Argon2id is the OWASP default; prebuilt napi is clean in Docker; bcrypt legacy-verify + rehash-on-login migrates silently.
  6. Ship the self-host rail (P0/P1). Distroless multi-stage image · compose.prod.yaml with bundled-DB/Neon profiles · Caddy TLS · SOPS+age secrets · WAL-G backups · pgvector-in-Postgres · OpenTelemetry → SigNoz.
  7. Identity stays Auth.js, gains a SAML/SCIM sidecar (P1). Auth.js is now maintenance-only under Better Auth — keep it for v1, add Ory Polis (SAML→OIDC + SCIM) so no rewrite is needed; Better Auth migration is a tracked P1.
  8. Turn the dormant CI gates on (P0). The local /ship gates run only on the operator's machine; enterprise requires them as hard, blocking CI checks — plus a new Prettier format gate and cosign/SLSA verify-on-deploy.
The one-line thesisThe foundation is correct; the work is operationalizing it for self-host and closing the AI-output governance hole — using the harness's own proven pattern (a gate plus a committed adjudication artifact) rather than inventing new mechanisms.
