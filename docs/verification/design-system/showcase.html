05 · Adoption

One edit rebrands everything

Tailwind v4 @theme + shadcn/ui + Tremor. brand.config.ts owns the hex → tokens.css the scale → globals.css the dark swap. Drop-in files live in adopt/.

brand.config.ts → tokens.css → globals.css
// the single white-label point (template ships indigo)
brand.primary = "#0165ff"  // royal, solid — no gradient
brand.font    = { sans:"Geist", mono:"Geist Mono" }
--color-primary: var(--brand-primary);  // bg-primary, ring, links
[data-theme="dark"] { --background:#05070e }  // one swap
