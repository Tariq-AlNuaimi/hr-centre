## 22. UI/UX

**Objective:** the whole UI/UX loop — building UI, component libraries/generation, encoded UX/design "taste" heuristics, and accessibility review. The ten repos split cleanly into four camps, and only two of them overlap with what this template actually does: **design-intelligence / anti-generic guidance** (ui-ux-pro-max, frontend-design, taste-skill), **component libraries + generators** (shadcn/ui, magic-mcp, shadcn MCP servers, openui), and **a11y review** (accessibility-agents, claude-a11y-skill, and the a11y slice of LibreUIUX). This template's answer is a _proactive-plus-reactive_ pair bound to gates: `/design-system` builds UI right on the first pass (one accent, one primary action, real empty/loading/error states, RTL + dark, on-token) and `/design-qa` drives Playwright to screenshot every component state + run **axe** and score each screen 0–5 against `docs/uat-rubric.md`, all on **Ant Design 6** primitives in `components/shared/*` with next-intl i18n/RTL. So we win decisively on _a11y-as-a-gate_ and _state-coverage discipline_, the component camp wins on _breadth of ready-made components_ (but for a different, shadcn/Tailwind stack we don't use), and the design-intelligence camp genuinely beats us on _encoded taste knobs_ — the one place worth borrowing.
