## 10. Security

**Objective:** app security, secret scanning, SAST, CVEs, security review.

Security is this template's strongest, hardest-gated area — 10 custom ESLint rules at `error`, mandatory `withAuth`/`withAdminAuth`/zod on every route, an automatic Prisma audit log, `SECURITY.md` + findings register, and the `/audit` skill that runs gitleaks + npm audit + Semgrep. Crucially, the template does not reinvent this category: it _consumes_ its two best tools (gitleaks #2, Semgrep #4) and mirrors the official AI reviewer (#5) via `/code-review` + `/security-review`. Where these repos win is at boundaries the template deliberately doesn't cover — container/IaC/SBOM scanning (Trivy), live-verified secret detection (TruffleHog), and the client-side "don't leak secrets _into_ the agent" guard (mintmcp) — so the recommendations below are additive, not replacements.
