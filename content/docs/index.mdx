Welcome. This site renders the project's internal documentation with search
and a navigation tree (press <kbd>⌘K</kbd> / <kbd>Ctrl K</kbd> to search).

- **Guides** live in `content/docs/**` — add a page by committing an `.mdx`
  file with a `title` frontmatter; it appears in the sidebar on the next build.
- **Architecture Decision Records** are pulled in from `docs/decisions/`
  unchanged and listed in the sidebar.

See [Adding pages](/docs/adding-pages) for the authoring workflow.
